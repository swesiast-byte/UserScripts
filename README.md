# UserScripts
User scripts  to use mostly with grease/tamper monkey


----
### Steps for installation
1. Install TamperMonkey extension on Chrome/Firefox/etc.
2. Pin the extension to browser toolbar
3. (Optional) Chrome might need allow user scripts permissions, Rightclick on the extension icon in toolbar -> Manage Extension > Click Allow User Scripts
4. Leftclick on extension in toolbar -> Create a new script
5. Copy the script from https://raw.githubusercontent.com/swesiast-byte/UserScripts/refs/heads/main/goodreadsFetchSteamRating.js and paste it into the new script, save
6. Go to any Goodreads book page and see the rating show up
